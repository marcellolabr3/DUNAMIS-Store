# DUNAMIS STORE

Loja virtual de vendedor unico para venda de produtos da igreja.

Esta etapa inicial configura a base tecnica com React, TypeScript, Vite,
Tailwind CSS, Vitest e Cloudflare Pages Functions.

## Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
npm run typecheck
npm run test
npm run test:coverage
npm run db:migrate
npm run seed:demo
npm run seed:clear
npm run deploy
```

## Desenvolvimento

```bash
npm install
cp .env.example .env
npm run dev
```
